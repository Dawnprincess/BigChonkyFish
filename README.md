# BongoCat 模型制作记录

假期期间做的一个 BongoCat 模型。

这里记录一下如何简单制作想要的模型，以及遇到的一些问题（包括未解决的）。

从一张平面图到模型大致需要三个步骤：

1. 将平面图转换为 PSD 分层图形，包含人物的各个部位。
2. 将分层图形的各个部件绑定物理效果。
3. 导出 Mver 格式的 moc3。

下面以“大肥鱼”为例。

## 第一步：准备平面图

我们需要一张大肥鱼敲键盘的图片。找一张尽可能清晰的正面图，以及初始的猫猫敲键盘图片，将这两张图发给 AI，让它绘制一张。

很幸运，在大肥鱼社区（[https://aigengtu.com/](https://aigengtu.com/)）找到一张很专业、清晰的三视图，然后用 AI 绘图也很方便。可能需要多画几张，挑一张满意的。

## 第二步：将图片分层

将绘制好的大肥鱼敲键盘图片分层。很幸运，See-Through 已经提供了解决方案，链接：[https://www.modelscope.cn/studios/ljsabc/See-Through](https://www.modelscope.cn/studios/ljsabc/See-Through)。

经过几分钟到十几分钟不等，可以得到结果。不过算法提取的结果细节可能不太好，可以自己找绘图软件稍微修改一下。这里我们得到 `大肥鱼.psd` 文件。

## 第三步：绑定物理效果并导出

将大肥鱼的各个部位绑定物理效果。使用 Cubism 当然可以，但对小白太难了，一些简单的人物模型可以（BongoCat 推荐的教程使用的就是这个）。

很幸运，有大佬做了一个 PSD2Live2D（需要以管理员模式启动），可以自动识别并绑定物理效果。导入 PSD 后大致看一下，会有细节不太好，后期手动调整（软件内含教程）。但导出的 moc3 并不能直接导入 BongoCat，需要转换为 Mver 格式。这里附带文档说明（可以交给 AI 去阅读解决这个问题）。

## 最后
很遗憾，大肥鱼的制作只绑定了鼠标（并且效果并不令人满意），甚至点击动作都没有实现，更不提后续的表情等一系列更好玩的东西。

由于本人是个小白，在导入 PSD 后手动调整期间踩了大量坑（注意，PSD2Live2D 这个软件本身的手动修改部分功能也并不算完善），手动调整极为困难。包含的问题我在 PSD2Live 作者本人的视频下面已经讲了，并且不限于那些。并且如果想使用 PSD2Live 自动绑定后，再用 Cubism 手动编辑，会发现打不开导出的 moc3 文件（不排除后续修复）。

作者后续没有太多时间继续创作，也有些烦于处理这些琐碎、本不应该是问题的问题了。这里记录一下，我给出了所有素材以及中间产物，希望大家喜欢，或者继续做下去。我也期待更可爱、完善的大肥鱼形象。
