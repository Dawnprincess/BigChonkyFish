假期期间做的一个BongoCat模型

这里记录一下如何简单制作想要的模型，以及遇到的一些问题（包括未解决的）
从一张平面图到模型大致需要三个步骤
1.将平面图转换为psd分层图形，包含人物的各个部位
2.将分层图形的各个部件绑定物理效果
3.导出mver格式的moc3

下面以大肥鱼为例
第一步
我们需要一个大肥鱼敲键盘的图片，找一个尽可能清晰的正面图，以及初始的那个猫猫敲键盘的图片，将这两张图发给ai，绘制一张。
这里很幸运在大肥鱼社区(https://aigengtu.com/)找到一张很专业清晰的三视图，然后绘图用ai实现也很方便，可能需要多画几张，挑一张满意的。

第二步
将绘制好的大肥鱼敲键盘的图片分层，很幸运,see-through已经提供了解决方案，这里付上链接https://www.modelscope.cn/studios/ljsabc/See-Through，经过几分钟到十几分钟不等，可以得到结果。不过算法提取的结果细节可能不太好，可以自己找绘图软件稍微修改一下，这里我们得到大肥鱼.psd文件。

第三步
将大肥鱼的各个部位绑定物理效果，使用Cubism当然可以，但对于小白太难了，一些简单的人物模型可以（BongoCat推荐的教程使用的就是这个）。很幸运，有大佬做的一个psd2live2d(需要管理员模式1启动)，可以自动识别绑定物理效果，导入psd后大致看一下，会有细节不太好，后期手动调整（软件内含教程）。但导出的moc3并不能直接导入BongoCat，需要转换为Mver格式，这里附带文档说明（可以交给ai去阅读解决这个问题）

很遗憾大肥鱼的制作只绑定了鼠标（并且效果并不令人满意），甚至点击动作都没有实现，更不提后续的表情等一系列更好玩的东西。由于本人是个小白，在导入psd后，手动调整期间踩了大量坑（注意，psd2live2d这个软件本身的手动修改部分功能也并不算完善），手动调整极为困难，包含的问题我在psd2live作者本人的视频下面已经讲了，并且不限于那些。并且如果想使用psd2live自动绑定后，再用Cubism手动编辑，会发现打不开导出的moc3文件（不排除后续修复）。
